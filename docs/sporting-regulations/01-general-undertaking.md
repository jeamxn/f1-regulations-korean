# 제1장: 총칙

## 1.1 규정의 범위

본 스포츠 규정은 2026 FIA 포뮬러 원 월드 챔피언십의 모든 측면을 규율한다. 모든 참가자, 드라이버, 팀 관계자는 본 규정을 준수해야 한다.

## 1.2 참가 자격

### 1.2.1 컨스트럭터 등록

챔피언십에 참가하고자 하는 컨스트럭터는 다음 조건을 충족해야 한다:

1. FIA에 유효한 참가 신청서 제출
2. 참가비 납부
3. 기술 규정 준수 확인
4. 재정 규정 준수 증명

### 1.2.2 드라이버 자격

모든 드라이버는 다음 요건을 갖추어야 한다:

- 유효한 FIA 슈퍼 라이선스 보유
- 최소 연령 18세 이상
- FIA 의료 검진 통과

## 1.3 경기 주말 일정

### 1.3.1 표준 일정

일반적인 경기 주말은 다음과 같이 구성된다:

| 세션 | 요일 | 시간 |
|------|------|------|
| 자유 연습 1 (FP1) | 금요일 | 60분 |
| 자유 연습 2 (FP2) | 금요일 | 60분 |
| 자유 연습 3 (FP3) | 토요일 | 60분 |
| 예선 (Qualifying) | 토요일 | Q1/Q2/Q3 |
| 결승 (Race) | 일요일 | 최대 2시간 |

### 1.3.2 스프린트 주말

스프린트 형식이 적용되는 경기 주말은 별도의 일정을 따른다.

## 1.4 포인트 시스템

### 1.4.1 결승 레이스 포인트

결승 레이스에서는 상위 10명의 드라이버에게 다음과 같이 포인트가 부여된다:

| 순위 | 포인트 |
|------|--------|
| 1위 | 25점 |
| 2위 | 18점 |
| 3위 | 15점 |
| 4위 | 12점 |
| 5위 | 10점 |
| 6위 | 8점 |
| 7위 | 6점 |
| 8위 | 4점 |
| 9위 | 2점 |
| 10위 | 1점 |

### 1.4.2 패스트스트 랩 포인트

결승 레이스에서 가장 빠른 랩 타임을 기록한 드라이버가 상위 10위 이내에 위치한 경우, 추가로 **1점**이 부여된다.

## 1.5 경기 진행

### 1.5.1 출발 절차

경기 출발은 스탠딩 스타트 방식으로 진행되며, 빨간 신호등이 모두 점등된 후 소등되는 시점에 출발한다.

### 1.5.2 안전차 (Safety Car)

위험 상황 발생 시 경기 디렉터의 판단에 따라 안전차가 투입될 수 있다.
